# 📊 Sales Performance Dashboard

## 📌 Project Overview

This project analyzes retail sales data and presents insights through an interactive dashboard built using Dash.

## 🎯 Objectives

* Analyze sales by region and category
* Identify top-performing products
* Understand monthly sales trends

## 🛠️ Tools Used

* Python (Pandas, Plotly)
* Dash (for dashboard)
* Jupyter Notebook

## 📈 Key Insights

* West region has highest sales
* Sales peak at end of year (seasonality)
* Technology category dominates
* Few products generate most revenue

## 📊 Dashboard Features

* Region filter
* Total Sales KPI
* Sales by Category chart
* Monthly trend
* Top 10 products

## 🚀 How to Run

```bash
cd app
python dashboard.py
```

Open in browser:
http://127.0.0.1:8050/
